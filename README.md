# Neocle International

수출·수입 대행 홍보 사이트입니다. 애플리케이션 소스는 **`web/`** 디렉터리에 있습니다.

```bash
cd web
npm install
npm run dev
```

프로젝트 루트에서도 같은 명령으로 켤 수 있습니다.

```bash
npm install --prefix web
npm run dev
```

브라우저 주소는 `http://localhost:4174` 입니다.

## 실행 스크립트

| 명령 | 설명 |
|------|------|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run start` | 빌드 결과 실행 |
